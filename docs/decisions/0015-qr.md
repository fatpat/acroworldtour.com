# 0015. rsc.io/qr for TOTP enrolment QR codes

Status: accepted
Date: 2026-10-19

## Context

TOTP enrolment shows the `otpauth://` URI as a QR code so authenticator apps can scan it. The page must stay free of inline scripts and external services, so the code is rendered server-side.

## Decision

Use `rsc.io/qr`: tiny, no transitive dependencies, BSD-3-Clause licensed, maintained by the Go team's Russ Cox. It produces the QR bitmap that is served as a PNG.

## Consequences

- The secret is never sent to a third-party QR service.
- Pinned at v0.2.0. The QR route takes the sealed, 10-minute enrolment value (never the plain secret) and answers with `Cache-Control: no-store`.
- Added with a one-line justification in the commit that first imports it.
