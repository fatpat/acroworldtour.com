# 0007. Tie handling

Status: accepted
Date: 2026-10-18

## Context

Spec 03 §14 #24: legacy tie-breaks differ per ranking and ranks are never shared.

## Decision

Every ranking list is ordered by `(score desc, display name asc, id asc)`. The displayed rank is shared for equal Round3 scores ("1, 2, 2, 4").

## Consequences

- Ordering is deterministic and identical everywhere.
- A sporting-code tie-break, if the owner adds one, replaces this record.
